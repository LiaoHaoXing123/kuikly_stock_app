## 新增踩坑经验

- **迁移到「我的」页后要重新点 2 次 Tab 才跳转？** 不是 bug：抽屉刚关闭或动画未收敛时第一下
  点击会被吞。真机验证时多点一次即可。
- **模拟器坐标换算**：该设备 `wm size` 报 1080x1920，但 `screencap` 出的是横屏 1920x1080。
  传给 `input tap` 的坐标要按 `1920/1080 ≈ 1.778` 从截图坐标放大。
- **抓 260ms 的转场中间帧**：`exec-out screencap`（含 PNG 编码+传输）要 300ms+，抓不到。
  改用设备端连拍 `adb shell 'for i in 1..8; do screencap -p /sdcard/f$i.png; done'` 再 pull，
  或临时放大 `settings put global animator_duration_scale`（**注意：Kuikly 的属性动画不受它影响**）。

## 颜色 token 全量替换（740 处 / 25 个文件）

脚本 `tokenize_colors.py`：把 `pages/` + `ui/` 里出现频次 ≥5 的硬编码色值换成 `AppColor.*`。
**跳过 `data/`**（`StockColors` 是 hex 来源，且 `AIVerdict`/`AlertEngine` 里的 `0x00FFFFFF`、
`0xFFFFFFFFFFFFFL` 是**位掩码不是颜色**，误替换会编译不过）。`AppTheme.kt` 自身也跳过。

- 结果：硬编码色从 1066 处 → 326 处（剩下的是频次 ≤5 的页面专属长尾色，保留合理）。
- 新增 ~30 个 token，值全部取自现有代码，**引用 token 不改变观感**。
  只有 4 个近似灰做了归一（`0xFF8A94A3`/`0xFF8993A1`/`0xFF7F8998` → `TEXT_SUB`，通道差 ≤8）。
- **`0xFFFFFFFF` 拆成两个语义**：脚本先统一折成 `SURFACE`（白底），再用 `fix_on_dark.py`
  把 52 处**前景白**改回 `ON_DARK`（判据：同行的 `color(` / `Color(` / `foreground =` /
  `else AppColor.SURFACE`，且该行不含 `backgroundColor`）。两者值相同，纯语义归位。
- ⚠️ **写替换脚本必须处理 `L` 后缀**：`0xFF697586L` 会被正则吃掉 `0xFF697586` 留下 `L`，
  产出 `AppColor.TEXT_SUB_DEEPL`。正则用 `0x[0-9A-Fa-f]{8}(?![0-9A-Fa-f])` 只能挡 9 位以上的
  （如 `0xFFFFFFFFFFFFFL`），挡不住 `L`。

## 日历页 P2 视觉改进

- **切月横滑动画**：两个 observable —— `monthSlideBase`（写入**不带动画**，用来把内容瞬移到
  对侧）与 `monthReveal`（`animate()` 挂在它身上）。`transform(Translate(percentageX =
  base * (1 - reveal)))`。
  关键点：`animate()` 按 `(observable 名, viewRef)` 注册且**注册后无法撤销**（`AnimationManager`
  只增不删），所以做不到「滑出用 150ms、滑入用 200ms」这种非对称时长——两个 observable 才能
  拆开方向，拆不开时长。两段各 150ms，合计 300ms。
  ⚠️ `Translate` 的 `offsetX/offsetY` 在序列化时会被丢掉（`toString()` 只输出两个百分比），
  位移只能用 `percentageX`（相对元素自身宽度）。
- 事件圆点最多 3 个，超出折成 `+N`；月历与图例之间加 1px 分隔线。
- 统计卡从纯色 `INK_PANEL` 改为 `Direction.TO_BOTTOM_RIGHT` 渐变（新增 `INK_PANEL_SOFT`＝
  `0xFF12355F`），压浅色页底时不那么硬。

## AI 页空状态「最近对话」预览（诊断方案 P1 最后一项）

- **新增 `ui/component/EntryCard.kt`** → `entryCard(press, tag, title, meta, titleColor, lines, onClick)`：
  白底圆角 + 边框 + 热区 + 按压反馈 + 无障碍角色的**条目卡壳子**。空状态的「推荐问题」与
  「最近对话」共用它（推荐问题那段原本是内联 30 行，现在 6 行）。
- **`util/TextUtil.kt` 新增 `relativeTimeLabel(at, now)`** → 刚刚 / N 分钟前 / N 小时前 / N 天前 /
  N 周前 / 更早。**故意不用日期**：commonMain 没有本地时区，按 UTC 换算日历日会在半夜前后错一天。
- **`ChatMainPage`**：`recentSessions(limit = 3)`（过滤掉 0 条消息的空会话，置顶优先再按
  `updatedAt` 降序）+ `recentSessionsKey()`（`id#title#updatedAt` 拼接的指纹）。
- **关键点：`vfor` 只接受 `ObservableList`**，这里是排序+截断的派生列表，喂不进去。
  试过三条路：① 维护一份派生 ObservableList —— 要 5 个 sync 点，容易漏；
  ② `ObservableList(...)` 每次新建（`FundFlowCard` 里的写法）—— 拿不到变更通知，不可靠；
  ③ **`vbind({ ctx.recentSessionsKey() })`** —— 指纹变了整块重建，无缓存、无副作用。选了 ③。

**真机验证（Pixel_6_35 / emulator-5556）**：
1. 无历史 → 「最近对话」整块不渲染 ✅
2. 造 2 条有消息的会话 → 出现 2 条，按新→旧排序，空会话不出现，时间显示「刚刚 · 2 条消息」✅
3. 点条目 → 切进该会话、消息还原 ✅
4. **停在空状态、从抽屉里重命名那条会话 → 预览标题实时变成 `AlphaRename`** ✅（这条证明 vbind 重建真的生效，不是靠页面重建蒙的）
