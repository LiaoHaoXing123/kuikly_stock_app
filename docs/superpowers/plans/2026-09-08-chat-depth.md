# 聊天能力深化实施计划

用户已授权直接实现。保留当前工作区已有修复和现有 API 配置。

1. 新增独立 chat 协议模块：会话上下文按完整轮次裁剪，v1 JSON 信封、卡片类型与数值校验、严格解析错误提示。
2. SSE 解码与工具调用合并：按事件读取、多片段 tool_calls 合并、完成标记校验，流式仅显示 text，完成后校验卡片。兼容不支持 streaming 的服务；只在明确不支持时退回普通请求。
3. Repository 将本会话历史和最近股票实体带入请求。走势图使用本地真实 K 线数据，不能用模型编造的价位。
4. ChatMainPage 使用独立流式预览、真实阶段提示、停止/重试，异步结果绑定请求和会话，失败/中止消息不进入有效上下文。
5. 用公共 Canvas 图表组件替换占位图，保留数值数组及历史恢复。
6. 回归测试：历史隔离/长度、坏 schema/图表数据、JSON 字符串分片、SSE 与工具分片、截断响应。Android 编译、测试并按设备可用性验证。
