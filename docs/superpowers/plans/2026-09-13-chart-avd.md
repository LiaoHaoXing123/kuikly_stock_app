# Chart and AI context implementation plan

Goal: Ship the first chart migration increment to verified Pixel_6_35 / emulator-5556.

Architecture: Bundle KLineChart in a restricted Android WebView, exposed as a Kuikly render view. Keep the existing chart available for comparison. Forward explicit selected candle/range actions to the native AI follow-up path; calculate range statistics in Kotlin. Historical data must remain labelled as a local snapshot.

- [x] Verify AVD configuration; launch on port 5556 and verify runtime AVD name/API/qemu.
- [x] Add bundled chart engine, license, restricted host and shared adapter.

This increment does not implement live provider polling or replace the data pipeline. The broader repository/events/tools migration remains subsequent work.
