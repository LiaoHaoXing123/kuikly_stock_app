# 股票 AI 助手首页与 API 配置重构设计

## 目标

将当前承载导航、长对话、行情入口和开发者设置的拥挤首页，重构为 C 方案“分层研究工作台”；新增支持多服务商、多模型和第三方 OpenAI Chat Completions 接口的 API 配置中心，并确保 API Key 不进入源码、APK 静态配置、日志或 Git 历史。

## 产品原则

1. 首页回答三个问题：今天市场怎样、用户需要关注什么、下一步去哪里。
2. AI 聊天是独立研究空间，不在首页堆叠长回答。
3. 市场事实由本地 SQLite 和确定性计算产生，AI 只负责解释，不生成行情数字。
4. 启动首页不调用收费 API；只有用户主动提问、分析或点击“AI 解读”才调用模型。
5. 密钥只加密保存在用户设备上，界面和日志始终使用掩码。

## 信息架构

### 首页：研究工作台

首页采用已批准的 C 方案，包含：

- 顶栏：产品名称、数据日期与新鲜度状态。
- 今日投资简报：市场涨跌家数、市场温度、自选异动数量和待处理提醒数量。
- 四个核心入口：问 AI、市场行情、自选与持仓、风险中心。
- 今日关注：优先展示触发提醒、自选技术信号和需要处理的风险。
- 底部导航：首页、行情、AI、自选、我的。

首页不展示完整聊天消息、开发者选项或长表格。

### AI 研究室

- 顶栏显示当前服务商和模型，点击可快速切换档案。
- 保留多会话、引用、复制、删除、快捷提问和一次性自动滚动。
- 回答采用“结论 → 关键价位 → 观察动作 → 可折叠依据 → 数据来源”的移动端结构。
- 多股对比取消五列紧凑表格，改为每只股票一张纵向卡片。
- 结论卡的支撑位和压力位提供“一键设提醒”。

### 风险中心

风险中心读取自选持仓的数量、成本、现价和行业，确定性计算：

- 总成本、总市值、总盈亏和收益率。
- 单只股票仓位占比与最大单股集中度。
- 行业仓位分布与最大行业集中度。
- 已触发和生效中的提醒。

没有持仓数据时展示引导，不用零值伪装有效分析。风险等级由明确阈值计算，不调用 AI。

### 我的

“我的”页面承载 API 配置、数据刷新、数据来源、隐私说明和应用信息。开发者设置从聊天抽屉中迁出。

## API 配置中心

### 多档案

每个 `AiProviderProfile` 包含：

- 唯一 ID。
- 显示名称。
- Base URL。
- 模型 ID。
- 安全存储中的密钥引用，不保存密钥明文。
- 是否启用工具调用。
- 创建时间与更新时间。

首次启动创建两个不含密钥的预置档案：

1. AgentRouter：`https://co.agentrouter.org/v1`，模型 `deepseek-v4-flash`。
2. DeepSeek 官方：`https://api.deepseek.com/v1`，模型 `deepseek-chat`。

用户可以新增、编辑、删除、测试和启用自定义 OpenAI Compatible 档案。至少保留一个档案；删除当前档案前必须先选择替代档案。

### URL 与协议

首版支持 OpenAI Chat Completions：

`POST {normalizedBaseUrl}/chat/completions`

规范化只移除末尾 `/`，不自动增加或删除 `/v1`。生产地址必须使用 HTTPS；仅 `localhost` 和 `127.0.0.1` 允许 HTTP，用于本地开发。

### 密钥安全

- 新版本不再将 `.env` 的 API Key 注入生成代码或编译进 APK。
- Android 使用 Keystore 生成不可导出的 AES 密钥，使用 AES/GCM 加密用户输入的 API Key；密文、随机 IV 和版本写入私有 SharedPreferences。
- Kuikly 公共层只通过 `SecureSecretStore` 接口按档案 ID 保存、读取和删除密钥。
- 列表仅显示末四位掩码；编辑时不回填完整密钥，空值表示保留原密钥。
- 网络和错误日志禁止输出 Authorization、用户提示词、模型回答正文和服务端原始错误正文。

### 连接测试

连接测试发送最大输出 8 tokens 的最小 Chat Completions 请求，要求模型简短回复。结果展示：

- 成功或失败。
- 请求耗时。
- 当前服务商和模型。
- 可行动的错误说明。

错误映射：

- 401/403：密钥无效或无权限。
- 404：Base URL 或模型 ID 不正确。
- 429：额度不足或请求过于频繁。
- 超时/无法连接：网络、DNS 或服务不可达。
- 2xx 但格式不兼容：服务未返回 Chat Completions 结构。

## 数据与状态流

`AiProfileStore` 保存非敏感档案元数据和当前档案 ID。`SecureSecretStore` 保存密钥。`AiRuntimeConfig` 在每次网络请求开始前读取当前档案和密钥，因此切换服务商或模型后无需重启。

如果当前档案未配置密钥，AI 页面展示配置引导，并继续允许本地行情、风险中心和离线模板能力运行。

`HomeDashboardService` 从 `StockDb`、`WatchStore` 和 `AlertEngine` 生成首页快照。页面进入前台或数据刷新完成后更新快照；短时间重复进入使用缓存，避免重复数据库查询。

## 回答排版与提醒联动

AI 结构化卡片补充机器可用的股票代码、支撑位数值、压力位数值、数据日期和指标日期。渲染层显示格式化字符串，提醒功能使用数值字段，禁止从自然语言中猜测价格。

用户点击“支撑位提醒”时默认创建“价格 ≤ 支撑位”；点击“压力位提醒”时默认创建“价格 ≥ 压力位”。保存前显示股票、方向和阈值供用户确认。

## 视觉规范

- 风格：克制的研究驾驶舱，而非密集交易终端。
- 主色：深海蓝承载摘要和判断，湖蓝承载操作；红色只用于上涨、强势和高风险提示，绿色用于安全与数据新鲜度。
- 首页卡片圆角与间距统一，正文不使用小于 12sp 的关键文本。
- 点击目标不小于 44×44dp。
- 所有可点击 Kuikly 组件添加可访问名称、角色和状态；重要文本不只依赖颜色表达。

## 代码边界

- `HomeDashboardPage`：只负责首页展示和导航。
- `HomeDashboardService`：生成首页快照。
- `RiskCenterPage`：展示风险数据。
- `PortfolioRiskCalculator`：计算持仓风险。
- `ProfilePage`：承载设置入口。
- `ApiConfigPage`：管理档案和连接测试。
- `AiProfileStore`：档案持久化与活动档案切换。
- `AiRuntimeConfig`：为网络层提供当前请求配置。
- `SecureSecretStore`：跨平台密钥接口，Android 使用 Keystore 实现。
- `DeepSeekApi`：改为通用 OpenAI Compatible 客户端，名称保留仅为迁移兼容，后续可重命名。

页面与业务计算保持分离，避免继续扩大现有 `ChatMainPage.kt`。

## 测试与验收

### 自动测试

- API 档案校验、序列化、切换、删除保护和掩码。
- Base URL 规范化、请求地址和 HTTP 错误映射。
- 首页简报生成与空数据状态。
- 持仓盈亏、单股集中度、行业集中度和零持仓边界。
- 结论卡提醒参数映射。
- 现有提示词、滚动和数据质量测试保持通过。

### 真机验收

- 升级安装后历史会话、自选和提醒不丢失。
- 首页五个导航入口可达，返回行为正确。
- 手机上新增 AgentRouter 档案密钥后连接成功，切换模型无需重启。
- 密钥在截图、日志、崩溃信息和 Git 中不可见。
- 发送后只自动滚动一次，用户上滑后不会被回复拉回底部。
- 多股对比卡、键盘输入、提醒创建、风险中心和大字体模式无明显截断。
- 冷启动、长列表滚动和内存指标不低于当前已测基线。

## 非目标

- 首版不实现 Anthropic Messages 协议。
- 不自动下单，不连接券商账户。
- 不在后台自动调用收费 AI 生成日报。
- 不抓取或编造当前数据库之外的新闻。
- 不把任何示例 API Key 提交到仓库或编译进安装包。
